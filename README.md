# Personal Website

A responsive personal website created to introduce myself, share a little about who I am, and provide visitors with an easy way to explore my background, interests, and goals.

This project was built using HTML, CSS, and JavaScript as part of my web development journey and demonstrates my understanding of responsive design, navigation menus, and interactive website features.


---

## About the Project

This website was created as a personal profile website to introduce myself online and showcase my interest in Information Technology and web development.

The goal of this project was to practice building a multi-page responsive website while improving my front-end development skills.

The website includes:

* Home page
* About page
* Gallery page
* Contact page
* Desktop and mobile navigation
* Hamburger menu for smaller screens
* Interactive JavaScript button
* Responsive layout and styling
